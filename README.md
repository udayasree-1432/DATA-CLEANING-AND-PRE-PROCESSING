# Excel Data Cleaning Project

## About the Project

This project is about cleaning a raw employee dataset using **Microsoft Excel**.

## Data Cleaning Performed

* Removed duplicate records
* Handled missing/null values
* Removed extra spaces
* Standardized gender values
* Standardized country names
* Corrected date formats
* Corrected age and salary formats
* Checked the final data for errors

## Tools Used

* Microsoft Excel
* Filters
* Remove Duplicates
* Find & Replace
* Excel Formulas

## Files

* `raw_dirty_employee_dataset.xlsx` – Original dataset
* `cleaned_employee_dataset.xlsx` – Cleaned dataset
